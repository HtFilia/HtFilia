# Profile artwork

The light and dark PNG headers in `assets/` are 1280 × 360 exports of the
paper-and-sage professional identity: Lucas Lebihan, Quantitative Engineer /
Quant Developer, Equity ETF · Delta One · Pricing, beside the portfolio's Fig. 1 (a simulated
geometric Brownian motion). The README uses native GitHub colour-scheme selection,
with a light fallback and a descriptive text alternative.

Editable SVG artwork, pinned fonts and the export script are maintained in the
author's private webfolio repository (`brand/` and `scripts/build-brand.mjs`). Copies
are committed here; viewing this profile does not depend on another repository
being public or on a dynamic image service.

## GitHub account fields

The profile README is versioned here. GitHub account fields are separate.
If the authenticated CLI token lacks the `user` scope, use GitHub's profile UI:

1. Open your GitHub profile and choose **Edit profile**.
2. Set **Name** to `Lucas Lebihan`.
3. Set **Bio** to `Quantitative Engineer / Quant Developer · Equity ETF · Delta One · Pricing`,
   the tagline shared with the portfolio, the résumé and LinkedIn.
4. Set **Location** to `Paris, France`.
5. Set **Website** to `https://lucaslebihan.dev/en/?ref=gh`; the `ref` tells the portfolio's
   server logs which visits GitHub brought.
6. Under **Social accounts**, add `https://www.linkedin.com/in/lucascjlebihan`.
7. Optionally tick **Available for hire**.
8. Save. Use the same headshot as LinkedIn as the avatar.

For repository social previews, open the repository's **Settings → General →
Social preview**, and upload its 1200 × 630 PNG from the identity package.
The compact README covers are already published and require no manual step.
